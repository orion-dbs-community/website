# KB OPENBIB

The [Kompentenznetzwerk Bibliometrie (KB)](https://open-bibliometrics.de/), a network of more than 25 German research institutions, contributes to the ongoing transformation towards open bibliometric data allowing for more transparency and participation in bibliometric research and contract work. But open bibliometric datasources require substantial data checks, cleaning and ongoing curation probably in a decentralised manner. We address these challenges by providing curated open data with a special focus on research from Germany.

Contact: [Christine Rimmert](mailto:christine.rimmert@fiz-karlsruhe.de) .

## oal_b_20250711

Description

##### Dataset Description

OpenAlex datasets provided by the KB follow the naming convention **oal_b\_\<openalex_snapshot_date\>** — for example, `oal_b_20250711` corresponds to the OpenAlex snapshot from mid-July 2025.

All data is structured according to a **bibliometric database schema** developed by the KB. This unified schema is designed to accommodate data from multiple sources and across different versions, making it easier to work with and compare data consistently.

###### Disambiguation Tables

Disambiguation tables are identifiable by the `add_` prefix and follow the naming pattern:

`add_<entity>_<source>_(<lookup>)_(<suppl>)`

The `source` field indicates the origin of the disambiguation:

- **`provider`** — disambiguation is supplied directly within the OpenAlex data
- **`kb`** — disambiguation has been produced by the KB

Tables *without* the `_suppl` suffix contain only entity assignments. Tables *with* the `_suppl` suffix include additional information in a more flexible format.

------------------------------------------------------------------------

For further details on the KB’s data infrastructure and processing pipelines, see the documentation on [Zenodo](https://zenodo.org/records/13935407). The table named mapping contains the source of the data in each column in the corresponding raw data format.

> **Note:** The KB infrastructure also holds licensed data that cannot be made publicly available. This data is therefore not present in Google BigQuery.
